## Automatic Detection Notes

- The hybrid full/interior LR counter automatically detects exact
  Kostka-translation shapes; the stretched DP table reports this as
  `Hybrid mode = kostka`.
- Generic stretched LR/Ehrhart evaluation is explicit, not automatic in
  `lrcoef_i64`. The current explicit path computes an h*-polynomial and
  then evaluates cached h* data at the requested stretch.
- A future ABI heuristic can detect a common dilation factor, divide to the
  primitive triple, estimate the dimension, and use h* evaluation only when
  the stretch is large enough to repay interpolation.
