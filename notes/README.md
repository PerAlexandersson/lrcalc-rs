# Notes

This directory keeps durable public notes for `lrcalc-rs`.

- [ALGORITHMS.md](ALGORITHMS.md): current implementation and algorithm map.
- [UPSTREAM_ABI.md](UPSTREAM_ABI.md): public C/Python/Sage ABI compatibility
  status.
- [LRCOEF_BENCHMARK_REPORT.md](LRCOEF_BENCHMARK_REPORT.md): generated
  benchmark report with exact coefficients and upstream `lrcalc` comparisons.

One-off profiling logs, local Sage benchmark output, and internal handoff notes
are intentionally not tracked here.
